## About

We work on **AI for Science** — mostly molecular modeling, multimodal foundation models, and the benchmarks / datasets / evaluation tools that go with them.

## Projects

### [BEAKER](https://github.com/HydroSophy/BEAKER) &nbsp;·&nbsp; *NeurIPS 2026 Spotlight*

**BEAKER: An Expert-Curated Benchmark for Embodied Brains in Self-Driving Chemical Laboratories**

A benchmark for MLLMs as embodied brains in self-driving chemical laboratories — 1,000 expert-curated questions, 11 image and video tasks across Actionability, Knowledge, Experimentation, and Reasoning, with 28 MLLMs evaluated.

[![Dataset](https://img.shields.io/badge/🤗_Dataset-BEAKER-FFD21E.svg?style=flat-square)](https://huggingface.co/datasets/HydroSophyTech/BEAKER)
[![Code](https://img.shields.io/badge/Code-GitHub-0B2A4A.svg?style=flat-square)](https://github.com/HydroSophy/BEAKER)

### [ToxiMol](https://github.com/HydroSophy/ToxiMol) &nbsp;·&nbsp; *KDD 2026 Oral*

**Breaking Bad Molecules: Are MLLMs Ready for Structure-Level Molecular Detoxification?**

A benchmark for molecular toxicity repair with MLLMs — 660 toxic molecules, 11 repair tasks, multimodal inputs (SMILES + 2D structures), plus the companion **ToxiEval** evaluation framework.

[![Paper](https://img.shields.io/badge/arXiv-2506.10912-b31b1b.svg?style=flat-square)](https://arxiv.org/abs/2506.10912)
[![Dataset](https://img.shields.io/badge/🤗_Dataset-ToxiMol--benchmark-FFD21E.svg?style=flat-square)](https://huggingface.co/datasets/HydroSophyTech/ToxiMol-benchmark)
[![Code](https://img.shields.io/badge/Code-GitHub-0B2A4A.svg?style=flat-square)](https://github.com/HydroSophy/ToxiMol)

### [ToxiEval-ZKP](https://github.com/HydroSophy/ToxiEval-ZKP) &nbsp;·&nbsp; *IFAC BIKA Best Paper Award*

**ToxiEval-ZKP: A Structure-Private Verification Framework for Molecular Toxicity Repair Tasks**

A structure-private, verifiable evaluation framework for molecular toxicity repair built on zero-knowledge proofs.

[![Paper](https://img.shields.io/badge/arXiv-2508.12035-b31b1b.svg?style=flat-square)](https://arxiv.org/abs/2508.12035)
